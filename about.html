About

Sea Bandits will be a new game similar to Seafight, albeit NO PAY2WIN features.
This project is written entirely in C++ using third-party libraries.

(Completed - Work in progress - Not started)

Isometric Map w/A* Pathfinding
Client/Server communication
Map editor - Data editor
Map switching System
Ship Designs - Elite Ship Designs
NPC's - Chatting - Quest systems
Guild systems - Guild islands
Quests - marketplace
Report system - Administration system

The game will be developed with oldschool Seafight concept in mind with some changes, but close to oldschool Seafight as you know it. The reason is because people are hungering for a good oldschool high-seas pirates mmorpg, needless to say that I am here to deliver.

The game is expected to release within the next few months (~October - November 2024).
